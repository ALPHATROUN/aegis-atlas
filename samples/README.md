# Synthetic import fixtures

Every file in this directory is fictional and safe for local demonstrations. The sample addresses, names, sites, and indicators do not describe a real environment. Use them to validate parsers, exercise the preview UI, and demonstrate quarantine behavior.

| File | Intent |
| --- | --- |
| `assessment-assets.geojson` | In-scope sites and services with approximate synthetic point geometry |
| `assessment-assets.csv` | Simple inventory import with one intentionally out-of-scope record |
| `assessment-nmap.xml` | Minimal authorized-lab Nmap-style result fixture |
| `assessment-nuclei.jsonl` | Minimal fictional Nuclei-style result fixture |
| `relationship-bundle.stix.json` | STIX-compatible infrastructure/location relationship preview |
