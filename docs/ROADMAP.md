# Product Roadmap

## Release 1 — Governed Assessment Atlas

The current release provides interactive Earth and local GIS context, scope-first assessment intelligence, evidence metadata, secure object-storage intake, task and delivery operations, report workflows, synthetic imports, analyst-confirmed assistance, and production documentation.

## Release 2 — Organization Operations

The next product increment should add full engagement administration, invitation and role management, reusable engagement templates, comment threads, reviewer queues, report approval states, configurable retention rules, client read-only report sharing, and notification delivery. These features make the workspace practical for a consulting practice or internal multi-team program.

## Release 3 — Interoperable Geospatial Intelligence

This stage should add authorization-gated OGC API Features connectors, STIX/TAXII import adapters, KML/GPX planning interchange, explicit imagery provider connections, metadata-preserving STAC catalogs, data-quality rules, and a governed 3D globe/building stream for organization-owned or approved data.

## Release 4 — Enterprise Governance

The enterprise release should add organization SSO, SCIM, advanced role and tenant policy, customer-managed encryption, regional data residency, audit export, legal-hold workflows, managed malware scanning, report sharing controls, and configurable deployment patterns.

## Product principle

Every roadmap item must improve **authorized assessment decisions** while retaining scope enforcement, provenance, analyst confirmation, privacy-aware coordinates, evidence custody, and a clear separation between public synthetic demonstration data and private customer data.
