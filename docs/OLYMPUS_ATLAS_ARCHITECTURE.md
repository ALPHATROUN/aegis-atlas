# Olympus Atlas Operating Architecture

## Product identity

**Aegis Atlas** remains the GIS-first, authorization-bounded assessment platform. Its Olympus treatment is a visual and interaction system for orienting analysts through geographic observation, relationship intelligence, evidence, and accountable decisions. It is not an Anubis Guard reskin, a mythology-only decoration, or a claim of live target access.

> **Design principle:** each Olympus chamber must explain the analyst’s current operational question before it impresses visually.

## Routed operating domains

| Route | Olympus chamber | Operational question | Core bounded workflow |
|---|---|---|---|
| `/` | **Acropolis Command** | What is changing across the authorized assessment? | Timeline, selected record, scope, audit and evidence snapshot |
| `/atlas` | **Helios Cartographium** | Where is the declared estate and how does geography change context? | Earth/local layers, synthetic AOI, coordinate context and GIS controls |
| `/surface` | **Ares Perimeter** | Which declared assets and exposure relationships require review? | Asset selection, ownership and service context |
| `/findings` | **Athena’s Tribunal** | Which findings are evidenced, owned, and ready for retest? | Bounded finding lifecycle and audit handoff |
| `/intelligence` | **Hermes Constellation** | How are assets, providers, services, and evidence related? | Relationship graph and source-grounded intelligence context |
| `/imports` | **Hephaestus Forge** | Is an allowed dataset valid, in scope, and quarantined when necessary? | Offline import preview, schema checks and governed quarantine |
| `/reports` | **Muses’ Archive** | Is the approved evidence basis ready for an audience-specific deliverable? | Synthetic report and safeguarded export preparation |
| `/operations` | **Zeus’ Stewardship** | Are delivery, governance, and tenant-grade controls ready for accountable use? | Enterprise readiness, delivery operations and no-action posture |

## Olympus visual system

Every chamber receives a different wide environmental field, layered with resilient gradients and motion-safe vector/ambient treatments. The imagery is intentionally atmospheric, leaving UI text and maps legible. Environments use named geographic/architectural metaphors rather than metric-card decoration.

| Chamber family | Palette and material | Semantic function |
|---|---|---|
| Acropolis / Helios | midnight cobalt, celestial gold, topographic marble | orientation, coordinates, sunrise-scale awareness |
| Ares / Athena | ember scarlet, weathered bronze, ink obsidian | exposure, judgment, accountable decision state |
| Hermes / Muses | electric cyan, lapis, parchment constellation marks | relationship flow, provenance, narrative delivery |
| Hephaestus / Zeus | volcanic copper, storm indigo, forge sparks | validation, governance, release and stewardship |

## Interaction contract

The left rail, compact mobile navigator, command palette, workspace header actions, map controls, and route-specific primary actions must each navigate, update a local bounded workflow, invoke an approved service procedure, download a local artifact, or state a specific unavailable prerequisite. Primary controls do not silently no-op.

## Safety boundaries

The Olympus architecture continues Atlas’s synthetic public mode. It does not perform active probing, exploitation, credential collection, provider mutations, ticket creation, remote sensing claims, external notifications, or autonomous actions. Geographic entities remain synthetic or restricted to customer-authorized private deployment flows.
